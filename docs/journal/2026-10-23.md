# 2026-10-23

## Chan 会议记录：v0.4.5（配网退出 / WiFi 自愈 / 识别链路体检）

### 修掉的根因
- **配网「退出配网」按钮无响应**：`loop()` 的 ST_PROVISION 分支提前 `return`，`pollInput()` 永远跑不到。补上即可。
- **重连风暴（最严重）**：`WebSocketsClient::loop()` 是 `if (millis() - _lastConnectionFail < _reconnectInterval) return;` → `setReconnectInterval(0)` = **立即无限重连**，不是关闭。实测 2 分钟 319 次设备接入，每次网关新开一个百炼 task。改为 `WS_RECONNECT_OFF_MS`(1 天) 表达关闭。**这条对"有时候能识别有时候不行"的影响最大。**
- **WiFi 偶发连不上**：实测 `reason=2 AUTH_EXPIRE`、`208 Association refused temporarily`（comeback time 被解析成 0xFFFFFFEA）。原来只 begin 一次；现在每 10s 重试 + 事件打点，3 秒自愈。
- **回显慢半拍**：WiFi modem sleep 让上行帧等 DTIM 信标（+100~300ms）。改 `WIFI_PS_NONE`。
- **丢采样**：Mic DMA 256×16(256ms) → 512×24(768ms)，盖住整屏重绘间隙。

### 网关（app.py）
- **百炼上行连接预热复用**：建会话 1.5s → **0.10s**。热连接同一时刻只给一个会话用（并发 recv 会 ConcurrencyError、两个活跃 task 会被拒），被占用时开专用连接兜底；异常退出补发 finish-task 防僵尸 task。
- **会议音频落盘**：`recordings/*.wav` 增量写 + 结束补头；`GET /recordings`、`GET /recordings/{name}`（带 token），配套 `make recs` / `make rec`。
- **热词表**：`assets/terms.txt` → DashScope `speech-biasing` create/update，md5 变了自动重建，run-task 带 `vocabulary_id`。实测已建 26 词。
- **音频体检**：每会话打印 `peak / rms / clip`，削波与过小在网关侧即可判定。

### 实测结论
TTS 生成的 16k 单声道 wav 走真实公网网关：**逐字全对**（含 模块/接口/数据同步/异常处理/张工），音频体检 peak=-3.3dB rms=-17.9dB clip=0.00%。
→ 模型、协议、采样参数、网关、热词均正常，误差只可能来自"设备实际录到的声音"或"VAD 裁剪"。
